# JavaScript Learning Log & Web Development

> **Goal:** Dominar JavaScript desde los fundamentos hasta la manipulación del DOM para crear páginas web interactivas y dinámicas.

---

## Metodología
* **Formato:** Receta/Procedimiento de 4-5 puntos clave.
* **Práctica:** 1 solo ejercicio en pantalla en blanco.
* **Depuración:** Analizar errores sin código servido en bandeja.
* **Regla de Progreso:** 3 victorias consecutivas para avanzar de tema.

---

## Ruta de Aprendizaje

### Fase 1: Fundamentos y Consola
- [ ] Variables (`let`, `const`) y Tipos de Datos
- [ ] Operadores Aritméticos y Concatenación / Template Literals
- [ ] Entrada y Salida Básica (`console.log`, `prompt`)

### Fase 2: Control de Flujo
- [ ] Operadores de Comparación y Lógicos (`===`, `!==`, `&&`, `||`)
- [ ] Condicionales (`if`, `else if`, `else`)
- [ ] Operador Ternario y `switch`

### Fase 3: Ciclos y Funciones
- [ ] Bucles (`while`, `for`)
- [ ] Declaración y Ejecución de Funciones
- [ ] Parámetros, Retorno (`return`) y Arrow Functions

### Fase 4: Estructuras de Datos
- [ ] Arreglos (`Arrays`) y Métodos básicos (`push`, `pop`, `length`)
- [ ] Objetos Literales (Propiedades y Métodos)

### Fase 5: Conexión con la Web (El DOM)
- [ ] Selección de elementos (`querySelector`, `getElementById`)
- [ ] Manipulación de contenido y estilos HTML/CSS con JS
- [ ] Eventos de Usuario (`addEventListener`: clics, inputs, formularios)
