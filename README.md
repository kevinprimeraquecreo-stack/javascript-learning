# Java Learning Log & CS Preparation

> **Goal:** Master Java fundamentals and Object-Oriented Programming (OOP) for Dual Enrollment and Web Development backend.

---

##  Metodología de Estudio
* **Formato:** Receta/Procedimiento de 4-5 puntos por tema.
* **Práctica:** 1 solo ejercicio práctico en pantalla en blanco.
* **Depuración:** Analizar mensajes de error del compilador (Bug Log) sin respuestas servidas.
* **Regla de Progreso:** 3 victorias consecutivas para avanzar al siguiente tema.

---

##  Fuentes de Apoyo
* **Práctica Principal:** [MOOC.fi (Universidad de Helsinki)](https://java-programming.mooc.fi/)
* **Consultas:** W3Schools Java / Exercism
* **Apoyo Visual:** Bro Code (YouTube)

---

## Ruta de Temas

### Fase 1: Fundamentos y Consola
- [ ] Estructura base (`public static void main`, `System.out.println`)
- [ ] Variables y Tipos de Datos (primitivos y `String`)
- [ ] Operadores Aritméticos y Módulo (`%`)
- [ ] Entrada de Datos (`Scanner`)

### Fase 2: Lógica de Control
- [ ] Operadores de Comparación y Lógicos
- [ ] Estructuras Condicionales (`if`, `else if`, `else`)
- [ ] Selección Múltiple (`switch`)

### Fase 3: Ciclos e Iteraciones
- [ ] Bucle `while` y `do-while`
- [ ] Bucle `for`
- [ ] Contadores y Acumuladores

### Fase 4: Métodos (Modularización)
- [ ] Creación de Métodos
- [ ] Parámetros y Retorno
- [ ] Ámbito de variables (Scope)

### Fase 5: Estructuras de Datos y POO
- [ ] Arreglos Unidimensionales (`Arrays`)
- [ ] Clases y Objetos
- [ ] Constructores y Encapsulamiento (`getters`/`setters`)
- [ ] `ArrayList` Básicos
